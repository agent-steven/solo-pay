# 개발자 가이드

SoloPay를 서비스에 통합하기 위한 기술 문서입니다.

## 시작하기

- [빠른 시작](/ko/developer/quick-start) - 5분 만에 첫 결제 연동
- [위젯 연동](/ko/widget/) - widget-js / widget-react 사용법 및 콜백 처리
- [주의 사항](/ko/developer/important-notes) - 연동 시 반드시 알아야 할 핵심 사항

## 상세 기능

- [결제](/ko/payments/) - 결제 생성, 상태 조회, 확정/취소, 환불
- [상점](/ko/merchant/) - 가맹점 등록, API 인증, 결제 수단 관리
- [웹훅](/ko/webhooks/) - 이벤트 수신 및 서명 검증
