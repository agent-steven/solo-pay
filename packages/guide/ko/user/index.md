# 유저 가이드

SoloPay로 결제하는 방법을 안내합니다.

## 시작하기 전에

SoloPay로 결제하려면 다음이 필요합니다.

- **MetaMask** 또는 **Trust Wallet** (브라우저 확장 또는 모바일 앱)
- 결제에 사용할 **ERC-20 토큰** 잔액

::: tip 가스비 없음
SoloPay는 블록체인 가스비를 대신 납부합니다. POL 등 네이티브 토큰이 없어도 결제할 수 있습니다.
:::

## Step 1: 지갑 선택

결제 위젯이 열리면 사용할 지갑을 선택합니다.

![지갑 선택](/images/user-guide/01-wallet-connect.png)

## MetaMask로 결제하기

### Step 2: 연결 승인

MetaMask 팝업이 열립니다. 계정을 선택한 뒤 **Connect**를 클릭합니다.

![MetaMask 연결 승인](/images/user-guide/02-metamask-connect.png)

### Step 3: 토큰 사용 승인

결제에 사용할 토큰의 거래를 승인하기 위해 위젯에서 **Approve Token**을 클릭합니다.

![토큰 사용 승인](/images/user-guide/03-token-approve.png)

### Step 4: 승인 트랜잭션

**Spending cap request** 팝업이 표시됩니다. SoloPay가 토큰을 처리할 수 있도록 승인하는 과정입니다. 화면의 안내에 따라 **Confirm**을 클릭합니다.

![MetaMask 토큰 사용 승인](/images/user-guide/04-metamask-approve.png)

### Step 5: 결제 내용 확인 및 진행

토큰 승인이 완료되면 결제 화면으로 넘어갑니다. 결제 금액, 네트워크, 가스비를 확인합니다. 가스비는 SoloPay가 부담하므로 **Free (Covered by Solo Pay)** 로 표시됩니다. **Pay Now**를 클릭합니다.

![결제 내용 확인](/images/user-guide/05-payment-confirm.png)

### Step 6: 결제 서명

**Signature request** 팝업이 표시됩니다. 최종 결제 승인 서명입니다. 가스비가 발생하지 않습니다. **Confirm**을 클릭합니다.

![결제 서명](/images/user-guide/06-metamask-sign-request.png)

### Step 7: 결제 완료

**Payment Complete** 화면이 표시되면 결제가 완료되었고, 결제 금액은 안전하게 보관됩니다. **Confirm**을 클릭하면 가맹점 페이지로 돌아갑니다.

![결제 완료](/images/user-guide/07-payment-complete.png)
